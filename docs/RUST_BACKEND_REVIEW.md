## 仍未闭环

- **HM-RUST-012 — scanner 记录与 staging 使用之间存在类型竞态。**
  `src/scanner.rs` 记录的节点类型在 `src/sys/fs.rs` 物化时没有重新核对；模块源目录在扫描与
  被读取之间若被改写，staging 可能按旧类型处理新对象。模块源目录按约定是只读输入，因此这是
  纵深防御而非已知可利用路径，但仍是未闭环项。
